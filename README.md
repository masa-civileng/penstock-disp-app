# penstock_disp（公開用）

導水管の変位・振動をスマホ動画から計測するブラウザツールの公開用リポジトリです。

- アプリ：https://masa-civileng.github.io/penstock-disp-app/
- 動画はブラウザ内だけで処理し、外部へ送信しません
- **Edge 推奨**（Chrome・Safari でも動作。iPhone 標準形式（HEVC）の動画は Chrome で読めないことがあるため）
- iPhone は「設定→カメラ→フォーマット→互換性優先」で撮影すると、どのブラウザでも読めます
- 起動時に CDN からライブラリを読み込むため、インターネット接続が必要

使い方の資料は別途配布しています。
